## 💡 Engineering Notes

I don't just want to memorize concepts.

For every topic, I try to understand:

1. **What is it?**
2. **Why does it exist?**
3. **How does it work?**
4. **When should I use it?**
5. **What are the trade-offs?**
6. **How would I design it at scale?**
7. **How would I explain it in an interview?**
